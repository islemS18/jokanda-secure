# Jokanda Secure

## Overview

Jokanda Secure is the administration platform for the Jokanda fabric store. It enables administrators to securely manage the online catalog by adding, editing, and deleting fabric products. The application also supports image uploads through Cloudinary and stores product information in Firebase Firestore.

## Features

* Secure administrator authentication
* Add, edit, and delete fabric products
* Upload product images using Cloudinary
* Store product data in Firebase Firestore
* Responsive and easy-to-use admin dashboard

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Firebase Authentication
* Firebase Firestore
* Cloudinary

## Purpose

The goal of this project is to provide a secure and efficient content management system for the Jokanda online fabric store, making it easy for administrators to keep the product catalog up to date.
